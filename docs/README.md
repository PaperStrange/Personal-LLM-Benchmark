# docs/ — start here

How this folder is organized. Living documents stay at the top level; history is
filed by kind.

| Path | What it is |
|---|---|
| `methodology.md` | The benchmark design — tasks, gates, metrics, evidence labels |
| `runbook.md` | Operations — how to run each gate, in what order |
| `backlog.md` | Product backlog — every planned iteration as an epic/story, with status |
| `sprints/` | Sprint plans, one per sprint, with acceptance criteria + definition of done |
| `knowledge/` | Living knowledge bases — updated as we learn |
| `iterations/` | Historical iteration proposals and design records (append-only) |
| `reviews/` | Plural-review records — findings and applied fixes, dated |

**New here?** Read `methodology.md`, then `backlog.md` for what's happening now,
then `knowledge/validation-knowledge-base.md` for what the evidence has shown.
